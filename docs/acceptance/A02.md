# A02 验收手册：数据 schema 与 manifest

## 1. 本次验收什么

A02 验证数据控制面最基础的可复现契约：

- `bars/v1`、`mark_bars/v1`、`funding/v1`、`contracts/v1` 四个 Arrow schema。
- 毫秒 UTC 时间、字段类型、null 语义、主键、排序键和 schema metadata。
- 精确 schema version 解析；`latest` 或未知版本不能静默回退。
- 逻辑 schema fingerprint，不依赖 Arrow IPC 的物理编码细节。
- 文件字节 SHA-256 与规范 JSON 内容 SHA-256 的明确区分。
- RawObject、Partition、DatasetSnapshot、Run 四类严格 manifest。
- manifest UTC、显式版本、相对路径、schema fingerprint、coverage 和生命周期约束。
- schema/manifest CLI 的成功输出和错误退出码。

本次不创建 DuckDB catalog，不下载 Binance 数据，不写 Parquet，也不发布正式数据集。

## 2. 环境更新

## 3. 自动验收脚本

执行：

```bash
cd /path/to/bfbt
source .venv/bin/activate
pytest tests/acceptance/test_acceptance_02_schema_manifests.py -v
```

预期收集并通过 12 个用例：

1. Registry 只包含四个明确的 v1 schema，且均有 64 位 fingerprint。
2. Bars 的主键、排序键、UTC、数值类型和 metadata 符合契约。
3. Mark bars 不伪造 volume；funding/contracts nullability 正确。
4. Arrow schema 经 IPC 往返保持一致，错误字段类型被拒绝。
5. `latest` 和未知 schema 不能解析。
6. 文件字节 hash 使用标准 SHA-256，规范 JSON 不受字典键顺序影响。
7. Raw fixture 能加载；嵌入凭证、坏 checksum 等输入被拒绝。
8. Partition 与 registry fingerprint、coverage 和安全相对路径绑定。
9. Dataset snapshot 拒绝 `latest` 和重复 dataset reference。
10. Run manifest 强制成功/失败/未完成状态的生命周期条件。
11. Manifest 规范 JSON 和内容 hash 可重复。
12. 实际 CLI 的 schema/manifest 成功和失败退出码正确。

预期末尾：

```text
12 passed
```

不应有 skipped、failed 或 error。

## 4. 人工 CLI 验收

### 4.1 列出 schema registry

```bash
bfbt schema list
```

预期四行，分别为 `bars/v1`、`contracts/v1`、`funding/v1`、`mark_bars/v1`，每行带 `sha256=`。

### 4.2 查看 schema

```bash
bfbt schema show bars v1
```

预期显示字段、primary key、sort key、metadata 和 fingerprint。以下命令预期失败且退出码为 2：

```bash
bfbt schema show bars latest
```

### 4.3 验证 Raw manifest

```bash
bfbt manifest validate raw \
  tests/fixtures/manifests/acceptance_02/raw_object.json
```

预期返回 0，并显示：

```text
Manifest is valid (raw-object/v1).
manifest_sha256=<64位十六进制字符串>
```

查看规范化内容：

```bash
bfbt manifest show raw \
  tests/fixtures/manifests/acceptance_02/raw_object.json
```

错误样例预期返回 2：

```bash
bfbt manifest validate raw \
  tests/fixtures/manifests/acceptance_02/invalid_raw_object.json
```

## 5. 相关代码
