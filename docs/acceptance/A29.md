# A29：共享输入参数 Sweep

## 验收能力

- `run_replay_sweep` 对已经一次载入内存的 selections/rankings/bars/funding 顺序推进多个
  独立候选，每个候选拥有独立账户、持仓、风险、成本和结果 hash。
- `run_chunked_replay_sweep` 每个时间块只从 LazyFrame 读取一次依赖行情，再对多组参数
  推进独立 checkpoint；共享市场块但不共享经济状态，不把 N 份市场数据常驻内存。
- 候选数有硬上限，逐阶段检查绝对 RSS；run 区间、Dataset、因子/调仓时钟或 selection
  不同的候选拒绝进入同一 sweep。
- sweep 返回研究摘要，不发布正式 run；选定组合仍通过普通正式 run 命令、缓存回放和原子
  artifact 发布，避免自动选优或覆盖旧结果。
