# A43 — General supervised Agent workflow

A43 is an entirely offline acceptance suite for the Agent control plane. It verifies:

- safe causal expression parsing, stable identity, symbol isolation, and gap-reset execution;
- original-text identity, strict registered/expression factors, and unresolved-ambiguity blocking;
- deterministic bilingual semantic, data, capability, cost, resource, and action planning;
- cost-drag confirmation and the Fast Matrix → human decision → Event route;
- plan-bound, expiring, action-specific authorization grants;
- recorded pause/resume hand-offs and DE-v1 readiness-chain verification;
- structured evidence summaries whose claims cite admitted hashes;
- public JSON schema, example intent, CLI validation, and side-effect-free planning.

```bash
python -B -m pytest -q tests/acceptance/test_acceptance_43_agent_workflow.py
```

The suite does not call a language model, access the network, download data, run market research,
or start a formal backtest. It tests the protocol with local fixtures. Real Quick Research, Fast
Matrix, and Event operations retain their existing separate authorization and immutable identities.
