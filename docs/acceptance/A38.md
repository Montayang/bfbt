# A38：曲线报告完整成交与持仓变化审计

## 不变量

- 曲线折线本身可以均匀降采样，但存在 `trades.parquet` 的报告必须把每个不同成交时点强制
  并入交互曲线和成交/持仓导航；同一时点的全部成交行都必须保留，不能设置成交数量上限。
- “上一笔/下一笔”和“上一处/下一处”不得跨过任何成交时点。一个时点存在多笔成交时，
  关联成交表同时显示该时点全部成交。
- 成交前后持仓必须从完整 `returns` 账本定位真实前一行与后一行，并优先查询该成交实际
  影响的合约；不得把降采样后的相邻曲线点表述为前后一分钟。
- Rank 与普通指令等高密度研究审计仍可有界抽样；它不能反过来裁剪成交、仓位变化或风险
  事件。成交关联的执行原因仍随每一笔成交保留。
- Fast Matrix 静态研究报告没有逐笔成交 artifact；一旦未来增加逐笔成交表，也必须遵守
  同一不变量。
