# A01 验收手册：配置与运行契约

## 1. 本次验收什么

A01 验证配置层能在任何数据下载或回测开始前完成以下工作：

- 安全加载 `data.yaml`、`universe.yaml`、`factor.yaml` 和 `backtest.yaml`。
- 拒绝未知字段，避免拼写错误被静默忽略。
- 校验 UTC 时间、左闭右开时间范围、周期整数倍、分位数和敞口。
- 校验行情、标记价格、资金费率、成交成本与运行方式之间的依赖。
- 区分可编辑的草稿配置和可执行的 run-ready 配置。
- 以仓库根为基准解析相对路径，不依赖执行命令时的工作目录。
- 只接受 `BIANBT_DATA_ROOT`、`BIANBT_OUTPUT_ROOT` 两个环境覆盖，不读取 API key。
- 为完全展开的配置生成不受 checkout 绝对路径影响的 SHA-256 指纹。
- CLI 对成功返回退出码 0，对配置错误返回退出码 2。

本次不测试行情下载、数据库、Parquet、因子计算或回测收益。

## 2. 环境搭建

以下命令均由用户在仓库中手动执行：

```bash
cd /path/to/bfbt
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e ".[test]"
```

要求 Python 3.10 或更高。A01 只安装 Pydantic、PyYAML、Typer 和 pytest，不安装数据计算包。

不需要复制 `.env`，不需要 Binance API key，也不需要联网访问 Binance。只有首次安装 Python 包时需要访问包索引。

## 3. 自动验收脚本

执行：

```bash
cd /path/to/bfbt
source .venv/bin/activate
pytest tests/acceptance/test_acceptance_01_configuration.py -v
```

预期收集并通过 10 个用例：

1. 默认四份配置能作为 draft 加载，数据和输出路径按项目根解析。
2. 固定完整样例满足 run-ready 要求。
3. 默认草稿一次报告所有缺失运行字段，而非逐个失败。
4. 非法 `long_quantile=0.6` 被拒绝，并显示字段路径。
5. 非 UTC 时间和非基础周期整数倍的周期被拒绝。
6. 使用标记价格估值但关闭 mark bars 时不能进入 run-ready。
7. 拼错的未知字段被拒绝。
8. 数据目录白名单覆盖有效，危险宽路径和未授权环境变量被拒绝。
9. 相同配置位于不同 checkout 路径时产生相同指纹。
10. CLI 成功路径退出码为 0，错误路径退出码为 2。

验收成功的末尾应类似：

```text
10 passed
```

如数量不是 10，以测试文件实际收集结果为准，但不应有 skipped、failed 或 error。

## 4. 人工 CLI 验收

### 4.1 验证默认草稿

```bash
bfbt config validate
```

预期：

```text
Configuration is valid (draft).
resolved_config_hash=<64位十六进制字符串>
```

### 4.2 验证完整可运行样例

```bash
bfbt config validate   --run-ready   --backtest tests/fixtures/config/acceptance_01/backtest.yaml
```

预期同样返回 0，并显示 `Configuration is valid (run-ready).`。该命令只校验配置，不会启动回测。

### 4.3 查看完全展开的配置

```bash
bfbt config show
```

预期输出所有默认值；其中路径使用相对项目根的稳定表示，例如 `data/backtest/datasets/default` 和 `data/backtest/runs`，方便写入未来 manifest。

### 4.4 验证错误退出

```bash
bfbt config validate   --backtest tests/fixtures/config/acceptance_01/invalid_quantile.yaml
```

该命令预期失败，shell 退出码为 2，输出包含 `portfolio.long_quantile`。这是预期的通过条件，不是程序故障。

## 5. 相关代码

- `src/bfbt/config/common.py`：不可变、严格字段模型与 UTC 校验。
- `src/bfbt/config/durations.py`：无歧义 duration 解析和周期倍数。
- `src/bfbt/config/data.py`：数据源、数据集、存储和质量配置。
- `src/bfbt/config/universe.py`：point-in-time universe 配置。
- `src/bfbt/config/factor.py`：因子、预处理和标签配置。
- `src/bfbt/config/backtest.py`：组合、执行、成本、风险和输出配置。
- `src/bfbt/config/bundle.py`：跨文件约束与 run-ready 校验。
- `src/bfbt/config/loader.py`：安全 YAML、路径和环境变量覆盖。
- `src/bfbt/config/fingerprint.py`：规范化配置和 SHA-256。
- `src/bfbt/cli.py`：面向用户的配置命令。
- `tests/acceptance/test_acceptance_01_configuration.py`：本阶段自动验收入口。

## 6. 反馈方式

验收后请提供 pytest 的完整末尾摘要；若失败，同时提供第一个失败用例的 traceback。人工命令若不符预期，请提供命令、输出和 `echo $?`。A01 经用户确认后才进入提交/push 和 A02。
