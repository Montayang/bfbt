# A30：全市场因子交叉开平仓

## 验收能力

- 新增通用 `factor_crossover` 选择模式：真正 `cross_above` 产生 LONG，真正
  `cross_below` 产生 FLAT；首次有效值不触发，缺口重置。
- 每合约状态为 O(1)，总状态 O(当前有效合约数)，跨分析块导出/恢复；只在因子时钟推进，
  只在调仓时钟发布信号。
- V2 增量指令接受策略 FLAT：只平已有仓，不反向、不为零仓位虚构成交；风险优先级和
  next-open 语义不变。
- 报告显示因子阈值、交叉方向、初始/缺口政策、固定保证金和独立多仓，不再声称使用 Rank。
- 跨块持仓合约停止出 bar 时沿用最后真实 close 估值；没有真实开盘的指令只审计为
  `END_OF_DATA_UNFILLED`，不会虚构成交。该最后价进入可恢复 checkpoint。
