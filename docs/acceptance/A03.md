# A03 验收手册：本地 DuckDB Catalog

## 1. 本次验收什么

A03 验证数据控制面的本地索引、版本解析和可恢复性：

- 从空目录创建 DuckDB，并用显式 `catalog_schema_version=1` 管理迁移。
- 初始化时登记 A02 的四个内置 schema，重复初始化不改变结果。
- 事务化登记 RawObject、Partition、DatasetSnapshot 和 Run manifest。
- 同一业务 ID、同一内容重复登记是幂等操作；同一 ID 的不同内容必须报冲突。
- Partition 必须引用已登记且 dataset 一致的 RawObject。
- DatasetSnapshot 必须引用已登记、版本/schema/fingerprint/质量报告/时间范围一致的 Partition。
- Run 必须绑定存在的精确 DatasetSnapshot 版本及其 manifest hash。
- 通过精确版本解析 DatasetSnapshot；不允许用 `latest` 隐式漂移。
- 查询一个事实数据版本的分区数、总行数、时间范围、symbol 峰值和质量报告。
- 从 manifests 按依赖顺序重建临时数据库，全部成功后原子替换目标；失败保留旧库。
- `bfbt catalog` CLI 的成功路径、负向退出码和可读输出。

本次不扫描 Parquet，不下载 Binance 数据，不做标准化、重采样、因子或回测计算。

## 4. 人工 CLI 验收

以下命令只在系统临时目录建库，不会写正式 `data/`：

```bash
cd /path/to/bfbt
source .venv/bin/activate
A03_WORKDIR=$(mktemp -d)
A03_DB="$A03_WORKDIR/catalog.duckdb"
A03_MANIFESTS="tests/fixtures/catalog/acceptance_03/manifests"
```

### 4.1 初始化和查看

```bash
bfbt catalog init --database "$A03_DB"
bfbt catalog info --database "$A03_DB"
```

两次输出都应包含：

```text
catalog_schema_version=1
schema_registry=4
raw_objects=0
partitions=0
dataset_snapshots=0
runs=0
```

### 4.2 按依赖顺序登记

```bash
bfbt catalog register raw "$A03_MANIFESTS/01-raw-2024-01.json" --database "$A03_DB"
bfbt catalog register raw "$A03_MANIFESTS/02-raw-2024-02.json" --database "$A03_DB"
bfbt catalog register partition "$A03_MANIFESTS/03-partition-2024-01.json" --database "$A03_DB"
bfbt catalog register partition "$A03_MANIFESTS/04-partition-2024-02.json" --database "$A03_DB"
bfbt catalog register dataset "$A03_MANIFESTS/05-dataset.json" --database "$A03_DB"
```

每次首次登记应显示 `registration=inserted`。重复执行最后一条应返回 0，并显示 `registration=already_registered`。

### 4.3 Coverage 与精确解析

```bash
bfbt catalog coverage bars bars-dataset-v1 --database "$A03_DB"
bfbt catalog resolve usd-m-perpetual snapshot-v1 --database "$A03_DB"
```

Coverage 应至少包含：

```text
partition_count=2
row_count=300
available_from=2024-01-01T00:00:00+00:00
available_to=2024-02-29T23:59:00+00:00
```

Resolve 应输出规范化 DatasetSnapshot JSON。下面命令应失败且退出码为 2：

```bash
bfbt catalog resolve usd-m-perpetual latest --database "$A03_DB"
echo $?
```

### 4.4 从 manifests 原子重建

```bash
A03_REBUILT_DB="$A03_WORKDIR/rebuilt.duckdb"
bfbt catalog rebuild "$A03_MANIFESTS" --database "$A03_REBUILT_DB"
bfbt catalog info --database "$A03_REBUILT_DB"
```

预期显示 `Catalog was rebuilt atomically.`，随后计数为 2 个 raw、2 个 partition、1 个 dataset snapshot、0 个 run。

临时工作目录不需要手工删除；它位于系统临时目录且不进入 Git。
