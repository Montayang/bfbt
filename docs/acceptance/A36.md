# A36：相位采样因子与 Event 参数研究报告

## 验收能力

- `sampled_mean_ratio:v1` 按基础 K 线的固定相位行距计算当前价格与采样均值之比；
  `sampled_mean_ratio_inverse:v1` 直接取负并拥有独立因子身份。
- 参数显式固定 `sample_interval` 和 `sample_count`；规划器将最大采样 lag 纳入 warmup。
- 每个抽样点同时校验精确时间差、完整性、有限性和正价格，缺口不能由 row shift 静默跨越。
- Event 参数父报告使用 sheets 页签索引多个独立不可变子 run，拒绝绝对路径和目录穿越链接。
- 权益非正等失败子 run 保持失败身份，以独立失败子页进入父报告；不得伪造成 -100% 成功结果。
- R5/R6 七月 runner 冻结 Rank5、固定三分之一保证金、5倍杠杆、真实成本和六个风险 profiles。

## 离线命令

```bash
.venv/bin/pytest -q \
  tests/unit/test_sampled_mean_factor.py \
  tests/acceptance/test_acceptance_07_factors_research.py \
  tests/acceptance/test_acceptance_36_event_parameter_study.py
```

预期覆盖正反公式、12点相位、缺口失败关闭、参数校验、注册表和父子报告安全边界。

## 真实运行

真实七月运行必须在代码和离线验收冻结后执行：

```bash
.venv/bin/python examples/run_sampled_mean_rank5_event_2026_07.py
```

运行器为 R5/R6 各发布六个正式 Event run、外部子报告、`summary.json` 和父 `report.html`；
所有生成数据位于 `data/backtest/`，不提交 Git。完成后逐一执行 manifest 文件哈希
核验，并登记 run ID、收益、回撤、换手、缓存命中和报告位置。
