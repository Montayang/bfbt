# A27：可复用分析与信号快照

## 验收能力

- `AnalysisSnapshot` 固定 DatasetSnapshot manifest hash、区间、universe、因子和实现版本，
  按时间块保存 factor values 与 universe。
- `SignalSnapshot` 引用精确 AnalysisSnapshot ID/manifest hash，固定选择状态和完整 Rank
  能力，保存候选 selections；`audit_top_n` 不改变信号 identity。
- 两级产物使用 staging 后原子发布，成功目录不可覆盖；文件 byte size、row count 和
  SHA-256 每次命中前全部验证。
- 父 hash 错误、文件缺失/篡改、identity 碰撞和表能力不足均 fail closed。
- 因子/数据/universe 改动使 analysis 失效；Rank/交叉选择改动只使 signal 失效；仓位、
  止盈止损和成本改动可复用两级快照。
