# A25：报告工作台视觉与可用性升级

A25 只修改报告展示层，不改变回测、成交、风险、因子或指标计算。报告仍由不可变运行产物
确定性生成，仍是可离线打开的单个 HTML 文件。

## 用户目标

- 默认页把净值走势、所选时点指标、持仓和关联成交放在同一工作区。
- 使用明亮、中性的页面底色；四项核心指标压缩并整合进顶部页签栏。
- 删除长期占位的鼠标操作说明，并缩短图表高度，让持仓与成交更早进入首屏。
- 使用页签区分“走势与交易”“策略说明”“完整记录”，避免所有内容堆在一条长卷轴上。
- 策略页再按因子、执行、仓位与风险分区；记录页按概览、指标、成交、持仓和警告分区。
- 各分区内容直接展示，不再套折叠控件；参数采用双列字段卡片，避免重新退化成长卷轴。
- 图表与右侧指标栏保持底边对齐；右栏指标卡随可用高度均匀舒展，不把空白转移回图表。
- 曲线绘图区进一步增高到 440 视图单位；坐标、图例、导航及右栏标签和数值同步放大。
- 右栏字段卡以内容驱动的最小高度和弹性行分配填满空间，不使用空白占位撑高。
- 降低两侧留白，在宽屏上优先把面积留给走势图。
- 曲线不做平滑；去掉每个采样点的圆点，只保留稀疏事件标记和一个选中标记。
- 纵轴明确标注 USDT，增加左侧安全边距并使用整数刻度，避免标签被裁切。
- 持仓与成交直接位于图表下方；Rank、指令和风险事件通过次级页签切换。
- 分别提供上一/下一成交、持仓和审计点导航；“快照”明确为非固定间隔的报告审计点。
- 成交附近同时读取前一分钟和后一分钟账本，直接对照成交前/成交后持仓。
- 成交按 `sequence` 执行顺序排列，并展示成交前、目标及成交后权重；一分钟内完成开平仓也不会丢失。
- 成交、仓位指令与风险事件优先进入有界报告载荷，普通 Rank 时点仍采用抽样。
- 桌面表格自动换行；窄屏表格转为“字段名—字段值”卡片，不依赖横向滚动条。

## 自动验收

环境沿用项目 `.venv`，不需要网络或 API key：

```bash
cd /path/to/bfbt
.venv/bin/pytest -q tests/acceptance/test_acceptance_17_event_report.py
```

预期：13 项通过。测试覆盖报告确定性、交互数据边界、V2 审计内容，以及 A25 的三页工作区、
图表工作台、纵轴单位和审计页签结构。

## 人工视觉验收

重建正式报告：

```bash
.venv/bin/bfbt report a17-8fa2ecc94424b878462a0395 \
  --output-root data/backtest/runs \
  --output data/backtest/reports/a17-8fa2ecc94424b878462a0395/report.html
```

打开：

`data/backtest/reports/a17-8fa2ecc94424b878462a0395/report.html`

重点检查：

1. 默认打开“走势与交易”，顶部指标已压缩进导航条，页面采用明亮底色。
2. 图表与右侧选中时点栏上下边缘对齐，字号明显可读；字段卡均匀利用高度，两栏均无无意义留白。
3. 图表不再显示长期占位的操作说明，关联持仓和成交在更短的首屏路径内出现。
4. 使用“上一/下一成交”逐笔检查，并确认开平仓点会显示成交前和成交后账面。
5. 点击曲线、起点、最大回撤、上一/下一审计点和期末，右侧/下方内容同步更新。
6. 图上不再铺满采样圆点，纵轴数字完整且明确为 USDT。
7. 持仓、成交无需横向拖动；缩窄浏览器或手机查看时，宽表自动变为字段卡片。
8. “策略说明”和“完整记录”各自通过内部页签切换主题，内容直接展示且无折叠层；打印时全部主题都会输出。
