# A05 验收手册：标准化、质量门与 DataStore

## 1. 验收范围

A05 验证 A04 不可变 Raw 对象到可研究 Parquet 数据面的完整边界：

- 校验 Raw 文件大小和 SHA-256 后解析 archive ZIP/CSV 或 REST JSON。
- 将 bars、mark_bars、funding 和 contracts 映射到 A02 的四个精确 Arrow v1 schema。
- 统一 UTC 毫秒时间、字段类型、排序、来源对象和确定性 dataset version。
- 生成重复键、空必填项、非有限数、OHLC、价格/数量、周期和缺口质量报告。
- 质量失败只保存报告，不发布 Parquet、Partition manifest 或 Catalog 记录。
- 质量通过后以 `.tmp` 写入、hash 校验并原子发布不可变 Parquet part。
- 重复运行保持同一版本、路径和 manifest，Catalog 登记幂等。
- DataStore 只接受显式 dataset version，以 Polars LazyFrame 下推时间、symbol 和列过滤。

A05 不包含 K 线重采样、跨 part compact、时点化 universe、因子或回测。一个标准化批次不能跨 UTC 月；同月可发布多个 part，后续扫描统一读取。 跨月研究由后续运行编排显式组合各月不可变版本并分块扫描，A05 不创建浮动的跨月 `latest`。

## 2. 环境

复用 `bfbt-acceptance` tmux 和现有 `.venv`：

```bash
cd /path/to/bfbt
source .venv/bin/activate
python -m pip install -e ".[test]"
```

A05 新增 Polars。依赖安装需要访问 Python 包索引；第 3–4 节验收全部离线，第 5 节明确访问 Binance 公共 REST。全程不读取 `.env`、不需要 API key。

## 3. 自动离线验收

```bash
cd /path/to/bfbt
source .venv/bin/activate
pytest tests/acceptance/test_acceptance_05_normalize_store.py -v
```

预期摘要：

```text
8 passed
```

用例覆盖：

1. archive bars 的精确 schema、UTC 边界和确定性版本。
2. Raw checksum/size 在解析前阻断篡改。
3. 重复键、坏 OHLC 和负数量触发质量失败且不发布。
4. Parquet、Partition manifest 和 Catalog 原子/幂等发布。
5. mark bars、fundingInfo enrichment 和 exchangeInfo filters 的独立语义。
6. Polars LazyFrame 的时间、symbol、列投影及可选文件 hash 校验。
7. 已有 Parquet 缺失 manifest 时拒绝接纳。
8. CLI 标准化、限制行数的扫描预览和禁止 `latest`。

## 4. 人工 CLI 验收

先在临时目录生成一个确定性、离线的 A04 风格 Raw ZIP 和 manifest：

```bash
cd /path/to/bfbt
source .venv/bin/activate
A05_WORKDIR=$(mktemp -d)
python tests/acceptance/prepare_acceptance_05.py "$A05_WORKDIR"
```

标准化并发布：

```bash
A05_MANIFEST="$A05_WORKDIR/raw-manifests/archive-bars-BTCUSDT-1m-monthly-2024-01.json"

bfbt data normalize bars "$A05_MANIFEST" \
  --raw-root "$A05_WORKDIR/raw" \
  --normalized-root "$A05_WORKDIR/normalized" \
  --partition-manifest-root "$A05_WORKDIR/partition-manifests" \
  --quality-root "$A05_WORKDIR/quality" \
  --database "$A05_WORKDIR/catalog.duckdb"
```

预期包含：

```text
publication=published
rows=1
quality=pass
catalog=inserted
```

记录输出中的 `dataset_version=a05-...`，然后执行版本固定扫描：

```bash
A05_VERSION=<上一步输出的精确版本>
bfbt data normalized-scan bars "$A05_VERSION" \
  2024-01-01T00:00:00Z 2024-01-01T00:01:00Z \
  --interval 1m --columns open_time,symbol,close \
  --normalized-root "$A05_WORKDIR/normalized" \
  --database "$A05_WORKDIR/catalog.duckdb" \
  --verify-hashes
```

应输出 `rows=1`、`BTCUSDT` 和 close `42050.0`。原样重复 normalize 应变为：

```text
publication=already_published
catalog=already_registered
```

将 scan 的版本改为 `latest` 应退出 2，并说明必须使用显式非 latest 版本。

## 5. 真实联网验收

此项需要访问 Binance USD-M 公共 REST，不使用 API key。脚本动态下载 BTCUSDT 最近已经收盘的 3 根 1m K 线，并执行 Raw 发布、checksum 复核、标准化、质量门、Parquet 发布、Catalog 登记和带 hash 校验的懒加载扫描：

```bash
cd /path/to/bfbt
source .venv/bin/activate
python tests/acceptance/run_acceptance_05_live.py /tmp/bfbt-a05-live
```

预期包含：

```text
live_acceptance=passed
quality=pass
rows=3
```

联网受所在地区的 Binance 访问策略影响；HTTP 403/451、DNS 或超时表示网络验收未通过，不能用离线测试结果替代。

## 6. 磁盘产物

```text
$A05_WORKDIR/
├── raw/                         # A04 不可变输入
├── normalized/bars/
│   └── schema=v1/dataset_version=<version>/interval=1m/year=2024/month=01/part-*.parquet
├── raw-manifests/               # RawObject manifest
├── partition-manifests/         # Partition manifest
├── quality/                     # quality/v1 JSON
└── catalog.duckdb
```

## 7. 代码索引

- `src/bfbt/data/normalize/core.py`：Raw 定位、四类 normalizer 和版本指纹。
- `src/bfbt/data/validation/reports.py`：质量策略、指标和报告。
- `src/bfbt/data/publisher.py`：质量门、Parquet 和 manifest 原子发布。
- `src/bfbt/data/normalize/service.py`：端到端编排和 Catalog 登记。
- `src/bfbt/data/storage.py`：版本固定 Polars LazyFrame 扫描。
- `src/bfbt/data/catalog.py`：精确分区 manifest 解析。
- `src/bfbt/cli.py`：`data normalize` 与 `data normalized-scan`。
- `tests/acceptance/test_acceptance_05_normalize_store.py`：自动验收入口。
- `tests/acceptance/prepare_acceptance_05.py`：人工离线 fixture 准备。
- `tests/acceptance/run_acceptance_05_live.py`：真实 Binance 公共数据闭环。

验收失败时请提供 pytest 摘要和首个 traceback；CLI 失败时同时提供命令、输出和 `echo $?`。A05 通过后按用户指示提交/push，再进入 A06 重采样与时点化合约池。
