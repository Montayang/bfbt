# A23：单持仓替换、权益保证金和同 K 线硬退出验收

A23 将真实策略的账户与退出语义实现为可复用配置，不把合约名、Rank 5、5 倍或
止盈止损百分比写死在执行器中。

## 完成内容

- 新增 `equity_margin_fraction`：请求名义价值为
  `fraction × 调仓时权益 × leverage`；费用、滑点和预留成本仍经过资金硬门缩放。
- 新增 `portfolio.holding.mode: single_position_replace`。
- `existing_signal: ignore` 时，已持有同一合约不会重复加仓。
- 新合约信号先平全部旧仓，再按平仓后权益开新仓；平仓和开仓是两条独立可审计指令。
- 单持仓模式收到同一快照多个信号时显式报错，不隐式挑选。
- 新增 `risk.fill_model: same_bar_trigger`，完整 OHLC 已知后在触发 K 线内退出。
- 止损/移动止损跳空采用更差可成交价；止盈采用触发价。
- 同一 K 线同时触发止盈止损时，`worst_case` 先执行止损。
- 风险参考成交价进入 checkpoint，跨 chunk 恢复不改变成交。
- 风险退出在事件优先级上阻止同一分钟重新开仓。
- 事件契约升级为 `events/v3`，新增 `ALREADY_HELD` 与
  `REPLACED_BY_SIGNAL`。

## 策略对应配置

~~~yaml
portfolio:
  sizing:
    mode: equity_margin_fraction
    fraction: 1.0
    reverse_policy: net_delta
  holding:
    mode: single_position_replace
    existing_signal: ignore

risk:
  leverage: 5
  fill_model: same_bar_trigger
  gap_policy: worse_executable
  intrabar_conflict: worst_case
  symbol_exits:
    stop_loss:
      enabled: true
      distance: 0.02
      action: close
    take_profit:
      enabled: true
      distance: 0.036
      action: close
~~~

`fraction: 1.0` 表示以全部权益作为保证金基数。启用真实手续费和滑点时，资金硬门会
把实际名义价值略微缩到 5 倍以下，以免开仓即超过可用权益；报告会展示实际成交名义。
