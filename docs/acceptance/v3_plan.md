## 协作规则

- 每阶段先完成代码、验收脚本和说明文档，然后停下等待用户检查。
- 未经用户明确许可，不运行 pytest、真实联网脚本、commit 或 push。
- 用户许可测试后，按该阶段文档执行；通过后是否 push 仍以用户当次指示为准。
- 不执行全年大容量压测。联网验收使用能覆盖真实全链路的代表性范围。
- 默认只修改本仓库；访问外部系统、私有数据或实盘区域仍需事先批准。

## 正确性总门

- 时间块为左闭右开，core 连续且不重复；warmup 不可写入 core 产物。
- 截面 Rank 每分钟覆盖当时完整的 point-in-time universe。
- 任意 chunk_interval 下经济结果相同。
- 恢复前验证配置、dataset、引擎和计划 identity，以及所有已提交文件 hash。
- 半写入块、越界路径、缺块、重复块和篡改必须失败或被安全忽略，不能静默采用。
- 状态和产物行数只随当前市场规模或输出磁盘增长，不随整月明细占用内存。
- V1 与 V2 in_memory 回归必须继续通过。
