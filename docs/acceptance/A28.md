# A28：确定性缓存回放与稀疏执行

## 验收能力

- 正式 chunked run 在 `reuse_mode=read_write` 时优先命中 AnalysisSnapshot 与
  SignalSnapshot；只改变仓位/风险/成本时不再扫描 universe 或计算因子/选择。
- 只有 AnalysisSnapshot 命中时，按原时间块从 factor parts 重建 Rank/交叉选择，不读取
  raw bars 重算 EMA。
- `sparse_execution=true` 为每个执行块读取候选信号、块首持仓和待执行风险状态所需合约；
  依赖闭包为空或无法证明时保守走完整输入。
- `performance.json` 记录两级 snapshot ID、manifest hash、命中状态及是否稀疏执行。
