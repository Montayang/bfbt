# A37：R5-T4 激活式移动止盈与滚仓保证金

## 冻结语义

- 移动止盈在此前已确认的 favorable extreme 达到开仓均价上方 5.8% 后激活；激活后按
  favorable extreme 回撤 2.8% 退出。当前 K 线 high 只在本 K 线风险检查完成后更新，
  不能在同一分钟内制造 high-first 的虚假路径。
- 固定止损为 2.8%，固定止盈关闭；风险检查、保守跳空成交和冲突优先级沿用 Event 引擎。
- 固定版初始权益 10,000 USDT、固定保证金 3,333.333333 USDT。
- 滚仓版初始权益 2,000 USDT，第一轮和重置保证金均为 200 USDT；每次完整平仓后用
  “实际投入保证金 + 扣除手续费/滑点并计入资金费率后的净盈亏”生成下一轮金额。
- 下一轮金额严格小于 80 或严格大于 1,000 USDT 时重置为 200；恰好等于边界不重置。
- 可用保证金不足时由既有约束缩小实际开仓，并以实际投入保证金作为该轮基数。
- 滚仓当前金额、活动保证金、轮内净盈亏、重置次数和最后重置原因进入 PositionCheckpoint，
  并由磁盘 checkpoint codec 完整读写；chunk 恢复必须与连续执行一致。

## 验收命令

```bash
.venv/bin/pytest -q \
  tests/acceptance/test_acceptance_15_position_sizing.py \
  tests/acceptance/test_acceptance_16_risk_state.py \
  tests/acceptance/test_acceptance_37_r5_t4_trailing.py
```

真实月度运行器只可在单独取得回测授权后执行：

```bash
.venv/bin/python examples/run_r5_t4_trailing_event.py \
  --month 2026-05 --variant ROLLING --factor-profile H2
```

运行器支持 2026-05、2026-06、2026-07 的固定数据快照，以 `--variant`
选择 FIXED 或 ROLLING；不指定变体时两者都运行。`--factor-profile M15` 保持既有
12 个、间隔 15 分钟的取样，`H1` 和 `H2` 分别只把间隔改为 1 小时和 2 小时。
默认值为 M15，因此旧七月入口及既有命令保持兼容。
