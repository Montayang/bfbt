# A14 验收：跨快照 Rank 与有界状态

A14 在 A13 当前截面 Rank 之上增加固定 lag 的历史引用。核心约束是无前视、按实际
快照序列计数，并且执行状态只保留最近 lag 个截面。

本阶段验收完全离线，不访问币安、不读取 API key、不写正式 DatasetSnapshot。

## 1. 本阶段完成范围

- 支持 `selection.clock=factor|rebalance` 和固定非负 `lag`。
- `lag=1` 表示严格使用所选时钟的前一个实际快照，不使用 wall-clock 减法猜测。
- factor clock 可以在 1h 因子、4h 调仓下引用 3h、7h 等前一个因子快照；
  rebalance clock 在同一决策下引用 0h、4h 等前一个调仓快照。
- 历史 Rank 合约与当前 eligible universe 相交；已失效合约记录
  `HISTORICAL_RANK_NOT_CURRENTLY_ELIGIBLE`，不补选。
- 第一段历史不足记录 `INSUFFICIENT_RANK_HISTORY`，不会读取未来快照。
- 选择诊断保存 decision time、rank source time、lag、clock、symbol、Rank、
  sample count 和稳定 reason code。
- `RankHistoryBuffer` 只保留最近 lag 个完整截面，状态行为 `O(N × L)`。
- chunk 边界把最小状态写入临时 Parquet，再从 Parquet 创建新状态对象继续运行。
- `max_rank_lag`、`max_rank_state_rows` 和既有 incremental RSS 预算共同形成资源门。
- 分块性能记录增加 `rank_state_rows` 与 Rank 选择诊断行数。

## 2. 明确未包含

- 不提供任意历史 Rank 查询，不在执行引擎中常驻完整历史宽矩阵。
- 完整 rankings 仍是分区/分块 Parquet 审计产物，不等于内存状态。
- 不实现 fixed margin、fixed notional、equity fraction 或 position fraction；
  属于 A15。
- 不实现止盈、止损、移动止损和风险调仓；属于 A16。
- V2 正式全链路仍受运行前保护；A14 验收组合状态层与 chunk 边界，真实 V2
  全链路在 A18 验收。
- 不做联网下载或全市场压力测试。

## 3. Fixture 与预期时钟

输入位于：

- `tests/fixtures/portfolio/acceptance_14/factor_scores.csv`

它包含 9 个连续 1h 因子快照（0h–8h），每个截面最多 3 个合约；调仓决策位于
0h、4h、8h。4h 时 AUSDT 失效。

当 `lag=1`：

| decision | factor clock source | rebalance clock source |
|---:|---:|---:|
| 0h | 不足 | 不足 |
| 4h | 3h | 0h |
| 8h | 7h | 4h |

因此 4h 时 factor clock 选择 3h 的 Rank 1 BUSDT；rebalance clock 找到 0h 的
Rank 1 AUSDT，但它在 4h 已失效，必须跳过且不能改选 BUSDT 或 CUSDT。

## 4. 资源边界

fixture 参数：

| 项目 | 数值 |
|---|---:|
| Rank 快照数 | 9 |
| 单快照最大合约数 N | 3 |
| 调仓决策数 | 3 |
| lag=1 期望状态行数 | 3 |
| lag=2 期望状态行数 | 6 |
| 正常测试 max state rows | 100 |
| 失败测试 max state rows | 5 |

理论上固定 `L` 的额外状态行数不超过最近 `L` 个截面行数之和，即
`O(N × L)`；不会随总回测快照数 `T` 继续增长。验收还用 2 行 batch 强制让同一
Rank 截面跨 batch，确认状态机只接收完整截面。

## 9. 失败定位

- 业务断言失败会显示 decision/source hour、symbol 或 reason code。
- 状态超限会包含 `max_rank_lag` 或 `max_rank_state_rows`。
- chunk 恢复只在 pytest 的 `tmp_path` 或正式 run 临时 `.work` 中写 Parquet。
- 本阶段不写 `data/`、正式 `runs/` 或联网日志。
- 失败时保留 `bfbt-acceptance:a14` 输出并通知 Codex 查看。
