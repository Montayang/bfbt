# A45 — Frozen one-shot LLM Event benchmark

## Purpose

A45 translates four one-shot model submissions into deterministic, result-blind Event state
machines for benchmark `llm-cs-202509-202608-v1`. It is an owner-directed use of BFBT and does
not add model-generated code execution or claim that any submitted strategy is profitable.

## Frozen contracts

- the original responses, model identities, independent effort labels, implementation audits and
  hashes are retained in the ignored experiment workspace;
- every strategy uses the same point-in-time top-100 universe, evaluation interval, exact dataset
  snapshot, initial equity, 5 bp taker fee, 2 bp slippage and terminal execution tail;
- decisions consume completed observations only, and scheduled orders cannot fill before the next
  minute open;
- four isolated accounts advance through one chronological minute stream; strategy-specific risk,
  buffering, cooldown, sizing and missing-fill rules remain distinct;
- weekly Parquet parts and checkpoints bound memory and preserve incomplete risk events across
  recovery; publication produces immutable run identities tied to source, snapshot and response
  hashes.

## Offline acceptance

```bash
python -B -m pytest -q tests/acceptance/test_acceptance_45_llm_benchmark.py
```

The suite covers balanced target construction, minimum-universe failure, causal funding inputs,
post-cost basket sizing, delayed fills, funding signs, benchmark overrides, symbol caps, pending
risk-event recovery and the submitted Kimi breaker timeout. It uses deterministic fixtures and
does not read the benchmark result period.

## Formal execution

Formal execution requires the ignored prepared snapshot, a clean tracked checkout and explicit
owner authorization. The runner freezes each submission identity before it scans data:

```bash
python -B scripts/run_llm_benchmark.py \
  --experiment-root data/backtest/experiments/llm-cs-202509-202608-v1
```

This is a long, resumable background job. Operators should launch it once, return control, and
inspect its recorded status only when requested. Results and comparison reports are separate work:
offline acceptance must never be described as a completed formal benchmark.

## Cost qualification

At 7 bp one-way friction, deliberately conservative full-replacement ceilings imply roughly 51.1%
of initial equity for daily turnover, 306.6% for six replacements per day, and 1,226.4% for hourly
replacement over 365 days. Buffering and partial retention can reduce realized turnover, but the
formal artifacts—not these bounds—must determine actual cost drag. The owner explicitly accepted
this risk before execution.
