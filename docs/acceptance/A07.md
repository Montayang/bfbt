# A07 验收手册：因子、标签与研究工具

## 1. 验收范围

A07 验证 A06 时点化合约池之上的研究层：

- Factor Protocol、显式 registry 和确定性 factor version。
- momentum、reversal、realized volatility、rolling quote volume、
  taker buy ratio 五类首批因子。
- lookback/rolling 只读取 `close_time <= timestamp` 的 bar。
- 时间缺口或未完成 bar 不会被滚动窗口静默跨越。
- winsorize、rank、zscore 只在当期 eligible universe 内执行。
- forward return 显式区分 signal、entry、exit，默认下一 bar 开盘入场。
- 标签缺少未来、未来有缺口、价格 bar 未完成时输出原因码。
- IC、Rank IC、分层收益、覆盖率和因子 rank turnover。
- 因子与标签只按 `timestamp + symbol` 对齐并报告实际样本数。
- CLI 要求精确数据版本、`history_start` 和 `future_end`，只输出有界预览。

A07 不产生目标权重，不模拟成交、手续费、滑点、资金费率或资金曲线；这些
属于 A08。因子缓存只固定版本键，本阶段不发布正式缓存 manifest。

## 2. 环境

复用 `bfbt-acceptance` tmux 和现有 `.venv`，没有新增依赖：

```bash
cd /path/to/bfbt
source .venv/bin/activate
python -m pip install -e ".[test]"
```

A07 验收全部离线，不访问 Binance、不读取 `.env`、不需要 API key。

## 3. 自动离线验收

```bash
cd /path/to/bfbt
source .venv/bin/activate
pytest tests/acceptance/test_acceptance_07_factors_research.py -v
```

预期摘要：

```text
16 passed
```

覆盖内容：

1. registry 精确暴露五类 v1 因子。
2. 修改信号时点后的价格不会改变历史 momentum。
3. 缺口或未完成 bar 的 lookback 输出 invalid，不跨越计算。
4. zscore 排除当期不 eligible 的极端值。
5. rank 映射为稳定的 `[0, 1]` 截面尺度。
6. reversal、成交额、主动买入比例和波动率公式。
7. 标签下一 bar 入场与 horizon 退出无 off-by-one。
8. 未来不足和未来缺口有不同 invalid reason。
9. IC/Rank IC、分层和覆盖率使用相同对齐样本。
10. rank turnover 使用共同 symbol 的相邻观测。
11. factor version 确定且禁止浮动 `latest`。
12. research CLI 暴露显式历史和未来边界。

## 4. 人工 CLI 验收

准备三合约、10 分钟的 A05 风格 Parquet、manifests 和 Catalog：

```bash
cd /path/to/bfbt
source .venv/bin/activate
A07_WORKDIR=$(mktemp -d)
python tests/acceptance/prepare_acceptance_07.py "$A07_WORKDIR"
```

记录输出版本：

```bash
A07_BARS_VERSION=<输出的 bars_version>
A07_CONTRACTS_VERSION=<输出的 contracts_version>
```

确认内建 registry：

```bash
bfbt research list-factors
```

预期包含 `momentum`、`reversal`、`realized_volatility`、`quote_volume`、
`taker_buy_ratio`，版本均为 `v1`。

运行完整研究预览：

```bash
bfbt research preview "$A07_BARS_VERSION" "$A07_CONTRACTS_VERSION" \
  momentum forward_return_2m \
  2024-01-01T00:04:00Z 2024-01-01T00:06:00Z \
  --history-start 2024-01-01T00:00:00Z \
  --future-end 2024-01-01T00:09:00Z \
  --base-interval 1m \
  --universe-config "$A07_WORKDIR/universe.json" \
  --factor-config "$A07_WORKDIR/factor.json" \
  --normalized-root "$A07_WORKDIR/normalized" \
  --database "$A07_WORKDIR/catalog.duckdb" \
  --quantiles 3 --verify-hashes
```

预期关键输出：

```text
factor_rows=6
label_rows=6
ic_rows=2
quantiles_rows=6
coverage_rows=2
turnover_rows=2
```

factor JSON 中每个时点有 AUSDT/BUSDT/CUSDT 三行，rank value 为
`0.0/0.5/1.0`；label 中 entry_time 等于 signal timestamp，exit_time 晚
2 分钟；coverage 的 `aligned_valid_count=3`。

## 5. 时间与内存边界

- `history_start` 必须覆盖 universe rolling 和 factor 最大 lookback。
- `future_end` 必须覆盖最后信号的 delay + label horizon。
- 因子路径只有 backward shift/rolling；label 是独立输出，不能传入 Factor。
- 核心接口均返回 LazyFrame；CLI 只对各结果执行 `head(limit).collect()`。
- A07 不联网补齐 overlap，也不把未来 label 列合并回 factor 输入。

## 6. 代码索引

- `src/bfbt/factors/base.py`：Factor 协议和结果契约。
- `src/bfbt/factors/registry.py`：内建 registry、版本和主计算管线。
- `src/bfbt/factors/{momentum,volatility,liquidity}.py`：首批因子。
- `src/bfbt/factors/transforms.py`：eligible-only 截面预处理。
- `src/bfbt/labels/forward_returns.py`：无 off-by-one 的 forward label。
- `src/bfbt/research/`：IC、分层、覆盖率、换手和组合评估接口。
- `src/bfbt/cli.py`：`research list-factors/preview`。
- `tests/acceptance/test_acceptance_07_factors_research.py`：自动验收。
- `tests/acceptance/prepare_acceptance_07.py`：人工 CLI 隔离数据准备。

验收失败时请提供 pytest 首个 traceback；CLI 失败时同时提供完整命令、输出
和 `echo $?`。A07 通过后按用户指示提交/push，再进入 A08。
