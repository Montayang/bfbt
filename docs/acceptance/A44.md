# A44 — Final open-source engineering gates

## Purpose

A44 closes BL06 without changing research economics. It verifies that public installation,
dependency updates, version tags, package construction, GitHub Releases, and external extension
claims have deterministic, fail-closed contracts.

## Scope

- universal, hash-locked runtime and developer environments;
- an offline manifest binding lock inputs, outputs, Python range, and exact generator;
- locked Ubuntu, CI, and release installation paths;
- tag/version/changelog equality;
- wheel/sdist path, package, metadata, and checksum inspection;
- a tag-triggered GitHub Release workflow with Python 3.10/3.12 verification;
- weekly, review-only dependency update proposals;
- explicit release, dependency, plugin, and compatibility policies in English and Chinese.

## Offline acceptance

```bash
python -B -m pytest -q tests/acceptance/test_acceptance_44_open_source_release.py
python scripts/release_tools.py check-lock
bash -n scripts/install_ubuntu.sh
```

The test constructs temporary lock and package fixtures. It must prove that stale lock inputs,
manually edited lock output, malformed/mismatched tags, extra wheel packages, unsafe archive paths,
or missing release wiring fail closed.

## Full release candidate gate

After the focused test, the complete offline suite must pass in the current checkout. GitHub CI
then repeats the frozen environment and suite on Python 3.10 and 3.12. A real tag is not required to
accept the implementation: tag creation is a separate owner publication action.

Before an actual release, bump both declared versions, finalize both changelogs, rerun the gates,
merge to `main`, and create one annotated or signed tag at that exact commit. The workflow must
publish exactly one wheel, one sdist, and `SHA256SUMS`; it must not publish a partial release.

## Explicit exclusions

- no market-data download, research run, or Event backtest;
- no PyPI upload token or implicit PyPI publication;
- no third-party runtime plugin loader;
- no rewriting of historical artifacts or tags.
