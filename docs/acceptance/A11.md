# A11 验收手册：双语交互式回测报告

## 1. 验收范围

A11 只改进正式回测的 HTML 报告和报告所需的因子说明元数据，不改变行情、因子数值、组合构建、成交、持仓、成本或收益算法。

新版报告包括：

- 中英文回测概览和核心指标卡。
- 因子中英文名称、公式、配置参数和中文白话解释。
- Dataset、市场、配置回测区间与实际账本估值区间。
- 因子计算、截面排序、调仓、下一根开盘成交和 mark-price 估值流程。
- 手续费、滑点、资金费率、敞口与杠杆配置。
- 成交摘要、最近十笔成交和最后估值时刻的实际持仓。
- 中英双语指标名称，不直接向用户展示内部 metrics 变量名。
- 明确说明回测结束边界不会额外制造强制平仓交易。
- 核心指标、因子公式、策略摘要、交互曲线和期末持仓直接显示。
- 数据版本、完整参数、详细指标、成交和警告通过按钮按需展开。
- 曲线悬停显示时点数据，点击快照显示当时持仓与关联调仓成交。
- 曲线和快照数量有上限，避免年度报告嵌入完整逐分钟持仓导致体积失控。

## 2. 环境

复用现有 tmux 和虚拟环境：

```bash
cd /path/to/bianbt
source .venv/bin/activate
```

不需要联网，不需要 API key，也不需要重新准备教程数据。

## 3. 自动离线验收

由用户执行：

```bash
pytest \
  tests/acceptance/test_acceptance_07_factors_research.py \
  tests/acceptance/test_acceptance_09_metrics_artifacts.py \
  -q
```

A07 验证因子注册与 Amihud 手算公式；A09 验证报告发布、artifact 完整性、双语章节、
交互 payload 上限、持仓快照和确定性重建。若失败，请保留第一个 traceback。

## 4. 使用已成功的真实 run 重建新版报告

原 run 目录不可修改，因此报告应输出到 run 目录之外：

```bash
DATA_ROOT=data/backtest
RUN_ROOT="$DATA_ROOT/runs"
REPORT_ROOT="$DATA_ROOT/reports"
RUN_ID="a09-810e171ba5207fb5ef3e7f7a"
mkdir -p "$REPORT_ROOT/$RUN_ID"

bianbt report "$RUN_ID" \
  --output-root "$RUN_ROOT" \
  --output "$REPORT_ROOT/$RUN_ID/report.html"
```

这条命令会先校验旧 run 的 manifest 和全部 artifact hash，再使用已有 `resolved_config.json`、`metrics.json` 和 Parquet 表生成新版 HTML；不会重新运行回测。

成功时应输出：

```text
run_id=a09-810e171ba5207fb5ef3e7f7a
report=/.../data/backtest/reports/a09-810e171ba5207fb5ef3e7f7a/report.html
```

## 5. 人工可读性验收

打开 `data/backtest/reports/a09-810e171ba5207fb5ef3e7f7a/report.html`，逐项确认：

- [ ] 顶部有总收益率、最大回撤、夏普比率和成交笔数。
- [ ] 因子显示“Amihud 非流动性因子 / Amihud Illiquidity”。
- [ ] 显示完整公式、24h 窗口、1h 计算频率和中文解释。
- [ ] 配置回测区间是左闭右开 `[2026-06-08, 2026-06-15)`。
- [ ] 实际账本区间单独列出，不与配置区间混为一谈。
- [ ] 执行规则说明做多最高 2 个、做空最低 2 个、4h 调仓。
- [ ] 成交位置说明为信号后下一根 1m K 线开盘。
- [ ] 手续费 4 bps、滑点 2 bps、资金费率和 mark close 估值均有说明。
- [ ] 指标、成交和持仓表头均为“中文 / English”。
- [ ] 最近成交与期末多空持仓非空且内容合理。
- [ ] 页面明确说明结束边界不额外强制平仓。
- [ ] 数据、完整指标、成交和警告默认折叠，点击后可展开。
- [ ] 曲线悬停能看到时间、净值、收益和回撤。
- [ ] 点击曲线或快照点后，时点收益、敞口、换手和成本会更新。
- [ ] 点击快照后能看到当时的多空持仓；调仓附近能看到关联成交。
- [ ] 开始、最大回撤、上一快照、下一快照和期末按钮均可用。

短短七天的年化指标可能非常夸张，这是样本长度问题，不是报告计算错误。

## 6. 正式新 run 的区别

外部重建不会改变旧 run ID，也不会覆盖旧 `report.html`。以后重新执行正式 `bianbt run` 时，由于报告版本和源码指纹已经变化，会产生新的 run ID；新 run 目录里的 `report.html` 会直接使用新版布局。
