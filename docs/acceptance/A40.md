# A40: BFBT public-release identity and language contract

## Scope

- The public brand, distribution, import namespace, module entry point, CLI, documentation, and
  repository links use `BFBT`/`bfbt`; no compatibility alias is retained because there are no
  external consumers of `import bianbt`.
- The English `README.md` is the repository front door and links to the standalone
  `README.zh-CN.md`.
- Public language explicitly states that BFBT is independent from Binance, has no affiliation,
  endorsement, sponsorship, or financial relationship, and is not investment advice.
- Human-facing HTML artifacts publish a compatibility English page, an explicit `.en.html` page,
  and an independent `.zh-CN.html` page. JSON, Parquet, manifests, hashes, and metric keys remain
  single and language-neutral.
- The language contract covers formal Event reports, Fast Matrix reports, factor-study indexes and
  child reports, Event parameter-study reports, Quick Research reports, and Showcase pages.

## Offline verification

```bash
PYTHONPATH=src python -B -m pytest -q \
  tests/acceptance/test_acceptance_40_public_release.py
```

The complete offline suite remains the release gate. Packaging installation must additionally be
verified from a clean environment before the GitHub repository is made public.

Current candidate result (2026-09-02): `334 passed in 21.58s` on Python 3.12.3 and pytest 8.4.2.
An editable installation and distributable wheel were built with setuptools 84.0.0; the installed
CLI and dependency metadata passed, and the wheel contains `bfbt` with no `bianbt` Python package.

## Deliberate boundaries

- Existing immutable runs are never rewritten to add language variants. They can be verified and
  rebuilt outside their run directory with the current renderer.
- The historical `bianbt.*` Arrow metadata namespace remains frozen inside v1 wire schemas because
  it participates in immutable DatasetSnapshot and run fingerprints. It does not provide an old
  Python import, distribution, CLI, or public brand alias.
- Source evidence, identifiers, formulas, warning payloads, and user-authored natural-language text
  remain verbatim when necessary for auditability; localization changes presentation text only.
- A hosted GitHub Pages Showcase is a future public-presentation enhancement, not part of this
  release and not represented as implemented.
