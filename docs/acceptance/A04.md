# A04 验收手册：Binance 原始数据采集

## 1. 验收范围

A04 验证公开市场数据从远端到不可变 Raw 层的边界：

- 生成并发现 USD-M 成交 K 线、标记价格 K 线和资金费率归档。
- 成对探测 ZIP/CHECKSUM，严格解析官方 checksum，校验 SHA-256 和 ZIP CRC。
- 流式写 `.part`，校验后原子发布；中断、坏 checksum 和上游修订不得覆盖正式对象。
- 对 K 线和资金费率做左闭右开时间范围的 REST 分页。
- 保存 exchangeInfo/fundingInfo 时点快照和每页原始响应。
- 重复采集幂等；成功对象可登记 A03 DuckDB catalog。
- 全流程不读取根目录 `.env`，不需要或接受 Binance API key。

A04 不解析 CSV/JSON 业务字段，不产生 Parquet，也不做数据质量、重采样、因子或回测；这些从 A05 开始。

## 4. 人工离线 CLI 验收

```bash
cd /path/to/bianbt
source .venv/bin/activate
A04_WORKDIR=$(mktemp -d)
A04_RAW="$A04_WORKDIR/raw"
A04_MANIFESTS="$A04_WORKDIR/manifests"

bianbt data archive-plan bars BTCUSDT \
  2024-01-01T00:00:00Z 2024-03-01T00:00:00Z \
  --interval 1m --frequency monthly

bianbt data archive-coverage bars BTCUSDT \
  2024-01-01T00:00:00Z 2024-03-01T00:00:00Z \
  --interval 1m --frequency monthly \
  --raw-root "$A04_RAW" --manifest-root "$A04_MANIFESTS"
```

第一条应输出 `candidates=2` 和两个无凭证 `data.binance.vision` HTTPS URL；第二条不联网，应输出两个 `status=missing`。

负例应调用不带时区的起点并返回退出码 2：

```bash
bianbt data archive-plan bars BTCUSDT \
  2024-01-01T00:00:00 2024-02-01T00:00:00 --interval 1m
echo $?
```

## 5. 受控联网核验

该步骤会访问 Binance 公共服务并在临时目录写一个 BTCUSDT 日包、少量 REST 页面和元数据快照；不需要 API key。只有用户明确授权联网验收时执行：

```bash
bianbt catalog init --database "$A04_WORKDIR/catalog.duckdb"

bianbt data archive-sync bars BTCUSDT \
  2024-01-01T00:00:00Z 2024-01-02T00:00:00Z \
  --interval 1m --frequency daily --workers 1 \
  --raw-root "$A04_RAW" --manifest-root "$A04_MANIFESTS" \
  --database "$A04_WORKDIR/catalog.duckdb"

bianbt data rest-klines bars BTCUSDT 1m \
  2024-01-01T00:00:00Z 2024-01-01T00:03:00Z --limit 2 \
  --raw-root "$A04_RAW" --manifest-root "$A04_MANIFESTS" \
  --database "$A04_WORKDIR/catalog.duckdb"

bianbt data snapshot exchange-info \
  --raw-root "$A04_RAW" --manifest-root "$A04_MANIFESTS" \
  --database "$A04_WORKDIR/catalog.duckdb"
```

归档命令首次应为 `downloaded`；原样重复后应为 `skipped` 且 catalog 为 `already_registered`。REST K 线应产生两页对象，snapshot 应产生一个对象。随后执行 coverage 应为 `verified`：

```bash
bianbt data archive-coverage bars BTCUSDT \
  2024-01-01T00:00:00Z 2024-01-02T00:00:00Z \
  --interval 1m --frequency daily \
  --raw-root "$A04_RAW" --manifest-root "$A04_MANIFESTS"
```

若所在地区或网络被 Binance 返回 403/451、DNS 或超时，单独记录网络结果，不把它混同为离线逻辑失败。

## 6. 代码索引

- `src/bianbt/data/sources/base.py`：请求、远端对象、page、结果和错误契约。
- `src/bianbt/data/sources/http.py`：无认证 HTTP、有界重试、原始字节流下载。
- `src/bianbt/data/sources/binance_archive.py`：归档发现、checksum、原子发布和覆盖率。
- `src/bianbt/data/sources/binance_rest.py`：K 线/资金费率分页与元数据快照。
- `src/bianbt/data/ingest/raw_store.py`：REST 原始响应和 manifest 发布。
- `src/bianbt/data/ingest/service.py`：并行下载及 catalog 登记时序。
- `src/bianbt/cli.py`：`bianbt data ...` 命令。
- `tests/acceptance/test_acceptance_04_ingestion.py`：A04 自动验收入口。
- `tests/fixtures/ingest/acceptance_04/`：固定离线响应。

验收失败时请提供 pytest 末尾摘要和第一个失败用例的完整 traceback；CLI 不符合预期时同时提供命令、输出和 `echo $?`。A04 验收通过后，再按用户指示 commit/push，然后进入 A05 标准化与 DataStore。
