## 2. 组合与执行口径

- 每个 QR-v1 通过的预测根数映射为一个对应的调仓周期，共 29 个信号调度。
- 方向调整后因子最高 20% 做多、最低 20% 做空，双侧等权；目标总敞口 100%、净敞口 0%。
- 源 K 线收盘形成信号，下一分钟真实开盘成交；使用 1m trade close 逐分钟估值。
- 初始权益 10,000 USDT；不使用动态保证金、止盈止损或 Event 风险仲裁。
- 两个成本口径都保留真实资金费：`zero` 不扣手续费/滑点；`realistic` 为 taker 4 bps
  加固定滑点 1 bp。
- 没有真实开盘价时不伪造成交：新目标不进入；既有持仓维持数量并延后调整，用上一有效
  收盘估值。

五月研究快照已补充实际 Binance 资金费率归档：K 线 28,572,210 行/642 合约，资金费率
87,614 条结算事件/531 合约；无资金费率归档的 111 个 K 线合约不伪造事件。六月沿用既有
正式快照。

## 3. 运行结论

- 29 个 zero run 全部成功且总收益全部为正。
- 29 个 realistic 尝试中 27 个成功走完整路径，但总收益全部为负；表现最好的是
  `Alpha66 × 15m × 20根`，收益仍为 `-2.40%`。
- `Alpha31 × 1m × 1根` 和 `Alpha66 × 1m × 1根` 的 realistic 路径因权益变为非正而终态
  失败；对应 zero run 分别为 `+555.71%` 和 `+386.98%`，说明这些理论毛收益完全不可用于
  推断可交易净收益。
- zero 表现最高三项为 Alpha31 1m/1根 `+555.71%`、Alpha66 1m/1根 `+386.98%`、
  Alpha31 1m/5根 `+305.69%`；其累计换手分别约 54,918、75,539 和 20,869 倍。
- 低频样例 Alpha18 15m/20根从 zero 的 `+18.09%` 变为 realistic 的 `-4.48%`；累计换手
  约 424 倍，实际手续费 1,628.71 USDT、滑点 407.18 USDT。

本研究登记为 `matrix-evaluated`，不产生 `matrix-qualified` 状态。按用户决定，Fast Matrix
不设置自动筛选规则；用户查看报告后人工决定哪些配置进入 Event，以及增加哪些事件逻辑。
从结果看，当前 4+1 bps 成本假设下没有 realistic 正收益配置；人工选择时不能用 zero 毛收益
代替可交易结论，并须显式考虑极高换手风险。

## 4. 执行与低内存事实

- 56 个尝试成功发布为不可变 `fm-*` 研究 run；两个权益归零尝试保留错误和耗时，但不伪造
  成功 run。
- 为完成 1m 调仓，TargetSchedule 的重复身份字段改为字典编码，整表结果哈希改为 10,000
  行分块哈希；报告统计不再把整列展开为 Python 列表。
- Alpha31/Alpha66 1m/1根各有 87,838 个可执行调仓时点和 21,598,876 行目标；单进程运行
  内存保持在 VM 8GB 边界内。5m 以上任务可按成本口径双核并行，1m 任务必须串行。

本研究没有读取七月 Fast Matrix，也没有运行 Event 引擎、相关性去重或参数敏感性测试。
