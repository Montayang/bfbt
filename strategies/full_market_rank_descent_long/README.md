# 全市场 Rank 递减做多策略族

- `family_id`：`full_market_rank_descent_long`
- 中文族名：`全市场 Rank 递减做多`
- 运行索引：[`runs.md`](runs.md)
- 变体注册表：[`variants.md`](variants.md)

本策略族共享全市场时点化合约池、截面 Rank 递减触发、单多仓替换、5 倍杠杆、硬止盈
止损、成本与资金费率、V2 chunked 执行和事件审计。因子定义或仓位方式不同，必须登记为
不同策略变体，不能只靠一次 run 的配置差异区分。

R5/R6 的多组固定止盈止损属于同一基础策略身份下的 Event 参数研究。每个 profile 仍有
独立配置哈希、不可变 run 和子报告；父 study 报告只负责统一索引，不能把不同经济路径
伪装成同一个 run。

R5-T4 是 R5 因子与 Rank 路径上的退出/仓位扩展：固定版沿用原固定三分之一保证金，滚仓版
使用独立的净盈亏滚仓状态。冻结语义见 [`r5_t4_trailing_spec.md`](r5_t4_trailing_spec.md)；
开发及两次七月正式回测均已完成；以后没有新的回测授权时不得再次执行正式 runner。

## 身份层级

```text
策略族 family_id
  └─ 策略变体 variant_id（因子 + 仓位等稳定经济语义）
       └─ 回测别名（变体 + 精确区间 + 修订序号）
            └─ 不可变 run_id
```

时间区间不属于策略名称。同一策略可以在不同区间重复使用；同一策略、同一区间如果再次
正式运行，以 `r02`、`r03` 递增，不覆盖先前结果。

`R2-202607-r01`；如果存在多个修订而用户未指定，必须列出候选 run，不能擅自选择。

保持原样，它们是审计事实；本注册表负责把历史身份映射到新的稳定变体名称。
